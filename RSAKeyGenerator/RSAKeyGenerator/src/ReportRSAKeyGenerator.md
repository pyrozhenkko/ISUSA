# RSA Key Generator

Простий Java-додаток для генерації пари RSA ключів (приватного та публічного) з їх збереженням у Base64 форматі.

## Опис

Програма генерує криптографічну пару ключів RSA розміром 2048 біт, кодує їх у Base64 формат та зберігає у файл `keys.properties`. Ці ключі можна використовувати для шифрування даних, створення цифрових підписів та інших криптографічних операцій.

## Вимоги

- Java Development Kit (JDK) 8 або вище
- Бібліотека Java Cryptography Extension (JCE) - входить до складу стандартного JDK

## Використання

### Компіляція

```bash
javac org/ccpc/RSAKeyGenerator.java
```

### Запуск

```bash
java org.ccpc.RSAKeyGenerator
```

## Результат роботи

Програма виконує наступні дії:

1. **Генерує пару RSA ключів** розміром 2048 біт
2. **Кодує ключі** у формат Base64 для зручного зберігання та передачі
3. **Виводить ключі у консоль** для швидкого перегляду
4. **Зберігає ключі у файл** `keys.properties` у форматі:

```properties
keys.private=<Base64-закодований приватний ключ>
keys.public=<Base64-закодований публічний ключ>
```
